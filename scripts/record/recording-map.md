# DeepSeek Harness Desktop 录制地图

## 录制表面

- 产品表面：真实 Electron Desktop，不使用外部浏览器模拟安装与启停。
- 入口：Desktop 内置“插件中心”，当前为单页应用状态，不依赖固定 Host 端口。
- 录制规格：1920×1080、16:9、30 fps、H.264、无字幕、无音频，保留虚拟鼠标与点击波纹。
- 目录来源：公开 npm 目录；本次确定包为 `mypet@1.0.7`。

## 首次引导

`mypet` 首次运行会显示“欢迎领养电子宠物”，且没有跳过按钮。正式镜头不录引导：预演阶段通过真实 UI 完成一次领养，再卸载插件但保留浏览器中的宠物数据。正式录制从“未安装、已有可复用宠物档案”的干净状态开始，安装成功后直接展示运行结果。

## 可录功能

| Feature | 入口 | 真实反馈 | 可录性 |
|---|---|---|---|
| `F003-trusted-installation` | 插件中心搜索 `mypet`，点击目录卡片“安装” | 确认授权、真实安装进度、Host 重连、Pet 悬浮层出现 | ready |
| `F004-installed-composition-management` | “已安装”中的 `mypet` 管理行 | 停用后包保留但 Pet 消失；重新启用后 Pet 返回并显示运行中 | ready |

## 关键选择器

- 搜索框：`input[aria-label="搜索插件"]`
- Pet 目录卡：`li[data-catalog-entry^="mypet@"]`
- 安装确认：`[role="dialog"]` 内信任复选框与“确认安装”按钮
- Pet 运行结果：`[title="点击开/关 · 拖动移动"]`
- Pet 面板：`.dshpet-panel`
- 已安装管理入口：`button[aria-label^="管理已安装插件："]`
- 管理动作：`[data-action="disable"]`、`[data-action="enable"]`

## 等待与证据

- 安装前捕获 Pet 运行节点数量，预期为 0。
- 安装确认后等待同一节点数量由 0 变为 1，并核对已安装投影为“已启用 / 运行中”。
- 停用后等待 Pet 节点由 1 变为 0，并核对行状态为“已停用 / 未运行”。
- 再启用后等待 Pet 节点由 0 变为 1，并把 Pet 面板作为最终效果镜头。
- 安装与启停期间等待真实事务状态结束；不使用固定假进度或 mock 数据。

## 风险

- Host 重启会改变页面来源端口，录制控制必须重新绑定当前 Electron 页面。
- npm 下载耗时不稳定，素版会保留真实等待，成片只允许剪掉无信息的静止等待，不伪造状态。
- `mypet` 的 UI 没有 `data-testid`；本次固定 `1.0.7`，使用其稳定类名与 title，并在预演中再次核对。
